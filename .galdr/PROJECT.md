# Project

## Mission
Build a reliable natural-language-to-SQL agent that turns user intent into safe, executable SQL workflows.

## Vision
Provide a practical assistant for analysts and engineers to query data faster with lower risk.

## Goals
- G-01: Deliver accurate SQL generation for the supported data sources.
- G-02: Improve safety guardrails for query validation and execution.
- G-03: Keep developer workflows maintainable with testable, modular components.

## Non-Goals
- Full BI dashboard replacement.
- General-purpose database administration tooling.
